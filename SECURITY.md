# Security Policy

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Instead, report vulnerabilities privately to project maintainers with:

- Description of the issue
- Reproduction steps
- Potential impact
- Suggested fix (if available)

## Response Expectations

Maintainers will acknowledge reports as soon as possible and work on a fix
based on severity and reproducibility.

## Disclosure

After a fix is available, maintainers may publish a security advisory and
credit reporters who choose to be acknowledged.
