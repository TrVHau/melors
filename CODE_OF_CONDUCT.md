# Code of Conduct

## Our Commitment

We are committed to making participation in this project a harassment-free and
welcoming experience for everyone.

## Expected Behavior

- Be respectful and inclusive.
- Give constructive feedback.
- Assume good intent.
- Focus on ideas, not people.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language
- Personal attacks or trolling
- Publishing private information without consent
- Any conduct that would be inappropriate in a professional setting

## Scope

This Code of Conduct applies in project spaces, issue threads, pull requests,
and related community interactions.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, and
other contributions that do not align with this Code of Conduct.

## Reporting

If you experience or witness unacceptable behavior, open a private maintainer
contact request through repository discussions or issue channels.
